## 🚀 Getting Started

Follow these steps to run the project on your local machine.

### Prerequisites

- Git installed on your computer
- A code editor such as Visual Studio Code
- Node.js and npm if the project uses a Node.js-based build tool

### 1. Clone the Repository

```bash
git clone https://github.com/RakeshRa26/My_portfolio.git
```

### 2. Open the Project Folder

```bash
cd My_portfolio
```

### 3. Install Dependencies

If your project contains a `package.json` file, run:

```bash
npm install
```

### 4. Run the Project

For projects configured with a development script, run:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

**Note:** If your portfolio is built using only HTML, CSS, and JavaScript, you can open `index.html` directly in your browser or use the Live Server extension in VS Code.
