# Rakesh Rawal Portfolio - Sequential Version

This version places every portfolio section in a separate, clean vertical sequence:

01 Home
02 About
03 Skills
04 Services
05 Projects
06 Development Journey
07 Contact
08 Footer

Built with:
- HTML5
- CSS3
- Vanilla JavaScript

Features:
- Responsive design
- Mobile navigation
- Dark/light mode
- Scroll reveal animation
- Active navigation while scrolling
- Contact form UI
- Project cards
- Skills, services and timeline sections

Run:
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html with Live Server.
